# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

update version Usage:
  5  *   bun run bump <version>      e.g.  bun run bump 0.3.0
  6  *   bun run bump patch          bump the patch part (0.2.0 -> 0.2.1)
  7  *   bun run bump minor          bump the minor part (0.2.0 -> 0.3.0)
  8  *   bun run bump major          bump the major part (0.2.0 -> 1.0.0)

## build

```shell
bun run build:win or bun tauri build
```
```shell
bun run build:portable
```

```shell
bun tauri dev
bun tauri android dev
bun tauri android build --debug
```
